## 查看与体验

- [单张编辑](http://127.0.0.1:3175/editor)
- [模板管理](http://127.0.0.1:3175/templates)
- [批量处理](http://127.0.0.1:3175/batch)
- [示例图库](http://127.0.0.1:3175/library)

建议按以下顺序体验：

1. 在账号截图上拖动框选邮箱或电话。切换马赛克与纯色，选中区域后拖动、拉伸或用参数面板调整位置。支持撤销、重做和编辑前后对比。
2. 选择“水印”，修改文字、颜色、透明度、旋转或九宫格位置。可切换 Logo，选择本地图片；也可开启全图平铺。

   水印和纯色打码的颜色控件使用 HeroUI 调色盘。点击色块展开颜色面板和色相滑条，也可输入十六进制色值或选择常用色；选色立即反映到预览，Esc 或点击外部关闭。

3. 保存为模板，自行选择是否包含打码区域。模板默认只包含水印；打码需要主动勾选。到模板页体验改名、删除与套用。
4. 另存新图，查看结果并下载真实编辑后的 PNG。返回图库会看到独立的新图。也可改为覆盖模式，演示同一图库条目的画面变化。
5. 顶部“批量”准备三张截图。在批量设置中选择模板，再进入逐张预览。含打码时必须确认每张的位置；单张调整不会改写模板。
6. 顶部更多菜单选择“保存失败一次”，提交批量保存，查看部分成功与失败。点击“仅重试失败”不会重复保存成功项。也可停止尚未开始的任务，再继续这些任务。

顶部细条是原型演示工具，不属于拟议产品界面。可切换正常保存、失败一次和重置；演示进度不代表服务器处理速度。

## 设计约定

沿用现有 Ariso 后台，以图片为编辑中心，不重做公共导航。桌面为工具栏、画布、参数面板与固定保存区；手机将参数放在画布下方滚动，保存区保持可见。

- 公共外壳直接复用 `AdminShell` 和主题选择器。品牌黄、水绿、暖白及深靛蓝文字来自正式全局样式；深色模式同源。
- 字体复用 Caveat 与 Noto Sans SC。按钮、表单、滑块、数字输入、颜色输入、开关、复选框、菜单、对话框、进度与通知使用已安装的 HeroUI 3；图标使用 Lucide。
- 布局与状态使用 Tailwind。局部 CSS 仅处理原型顶部细条占用的外壳高度、画布棋盘背景与减少动态效果；画布直接由 Konva 承担。
- 不修改 Figma。本轮评审对象是独立可操作页面，不能将其作为正式产品的设计还原验收。

## 真实能力与演示边界

**真实执行：** 浏览器本地图片读取、多个矩形框选/移动/缩放、马赛克、纯色遮挡、文字与图片水印、旋转/透明度/平铺、配方复制、撤销重做，以及完整尺寸 PNG 合成与下载。Canvas2D 负责合成，Konva/react-konva 负责交互，预览与下载使用同一合成器。

**演示状态：** 图库、另存/覆盖、模板保存、批量队列、失败重试与停止。状态只在当前页面会话内存中保留；刷新整个页面会重置。另存将合成结果加入示例图库，覆盖仅更新内存中的示例条目。保存模式在开始时冻结。

没有数据库、业务 API、S3、正式文件写入、真实上传、外链更新、分享撤销、派生版本重建或服务器重启恢复。Logo 文件只在浏览器本地读取。本原型统一下载 PNG；正式格式保留策略仍按方案另行实现与验证。

动画示例使用静态占位素材，界面明确不可编辑，不代表已实现 GIF 解码。固定示例名称、尺寸与场景仅服务评审。长文本的排版、全部格式及大图性能不作为生产能力承诺。

## 本地运行

根项目依赖使用锁定版本。进入 Node 24 环境后：

```sh
pnpm install --frozen-lockfile
pnpm --dir prototypes/image-editor install --ignore-workspace --frozen-lockfile
pnpm --dir prototypes/image-editor typecheck
pnpm --dir prototypes/image-editor test
pnpm --dir prototypes/image-editor build
pnpm --dir prototypes/image-editor start
```

开发时使用 `pnpm --dir prototypes/image-editor dev`。端口为 `127.0.0.1:3175`，不执行主应用初始化。构建前停止该原型的开发服务，避免共用 `.next`。原型的独立锁文件仅增加 Konva 与 React 绑定；React/ReactDOM 连接根项目同一份依赖，避免双实例。

生成目录由本目录 `.gitignore` 排除。定向静态检查使用 `pnpm exec eslint prototypes/image-editor/app prototypes/image-editor/generate-fixtures.mjs --max-warnings=0`。
