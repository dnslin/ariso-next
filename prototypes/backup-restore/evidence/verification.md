## 桌面流程

- 创建密码与确认密码不匹配时显示字段错误，可修改后继续。
- 开始备份前展示暂停修改确认；开始后进入图库，删除按钮禁用，图片预览仍可打开。
- 公开图片页面实际加载本地演示图片（原始宽度 3888），不因备份状态拒绝访问。
- 备份完成后显示历史记录并恢复修改；实际下载 `ariso-demo.backup`，再在恢复页通过文件选择导入。
- 错误备份密码保留文件与输入，显示密码错误；正确演示密码进入摘要。
- 两个新 S3 均可配置。第一个模拟连接失败后保留输入，再次测试通过；第二个测试通过后进入恢复确认。
- 开始恢复，在约 12% 时刷新，仍显示原恢复任务进度；复制结束后显示等待重启，刷新仍保持此状态。
- 模拟重启完成后要求重新登录；填写演示密码后到达 `/library?restored=1`，删除按钮恢复可用。
- 删除备份确认后记录移除；取消正在执行的备份后修改操作恢复。模拟读取失败显示“备份未完成”和可操作的重试入口，暂停状态解除。
- 在新一次备份仍暂停修改时重新打开公开外链，实际图片加载成功。最终两种桌面主题（1440×1080）均无横向溢出，最后一轮未收到浏览器 Runtime.exceptionThrown 事件。

手机、平板、主题与短视口的 41 组状态检查由 `responsive.json` 保存，覆盖 360/390/430/768 宽和 390×600 短视口，均无横向溢出。真实 Tab 导航确认焦点能滚动到固定底栏上方。版本不匹配阻止继续；纯本地恢复无需 S3 配置，模拟复制失败后可重试至等待重启。10 张手机截图均已实际查看。

最终全工作树 `node node_modules/prettier/bin/prettier.cjs . --check`、`git diff --check` 和本地文档链接目标检查通过。`git diff --exit-code HEAD -- src drizzle package.json pnpm-lock.yaml compose.yaml` 通过，确认这些业务源码和配置未改变。原型界面与功能结果仍需用户最终查看，不标记为用户验收通过。

## 过程中发现与处理

- 分工整合时恢复主组件尚未落盘，最初编译缺少模块；完整文件落盘后类型检查和生产构建通过。
- 首轮 ESLint 指出图片元素及 effect 内同步更新状态；改用 Next Image、客户端初始化与独立保存逻辑后通过。恢复页 Lucide Image 图标改为 ImageIcon，避免被误认为 HTML 图片。
- 受控确认框和图片预览改用 HeroUI 独立 Backdrop，避免缺少触发按钮的 PressResponder 提示。
- 手机固定底栏可能遮挡自动滚入的表单操作，补充原型内滚动留白与控件 scroll-margin，并进行后续焦点复查。
- 开发热更新曾重置正在检查的恢复页面；最终检查切换到稳定构建，未将热更新中断记为业务失败。
- 浏览器检查脚本曾遇到并发原生输入超时、折叠表单不可点击，以及把带查询参数的登录跳转误判为超时；改为串行操作、展开对应表单并核对实际 URL 后继续。没有修改产品行为来迎合脚本。
