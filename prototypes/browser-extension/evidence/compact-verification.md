# 精简小窗原型验证

- 日期：2026-10-25。
- 用户反馈：上一版“好大，一点都不简约”。本轮将日常界面收为约 360px 宽的小窗，默认高度约 320px；旧版记录保留在 [verification.md](./verification.md)。
- 本轮只修改原型及方案／任务文档。真实扩展和后台接口尚未实现，新版仍待用户体验。

## 界面变化

默认只保留 Ariso、设置图标、拖入／粘贴／选择入口和可见性提示。加入图片后显示紧凑列表，列表内部滚动；上传或复制随状态出现。连接、可见性、链接版本、相册／标签／存储和外观进入设置视图。演示工具另行折叠，不属于正式产品。

网页右键保存回到同一个小窗。即使此前正在设置视图，新增网页图片也会回到上传列表。长站点地址不会把设置内容撑宽，点击后可在连接表单中完整查看。

## 实际检查

环境沿用 Node `24.18.1`、pnpm `11.19.0` 和仓库既有依赖，未新增依赖。以下命令实际执行并通过：

- `pnpm --dir prototypes/browser-extension typecheck`
- `pnpm exec eslint prototypes/browser-extension/app --max-warnings=0`，最终设置布局修正后又定向检查该文件。
- `pnpm --dir prototypes/browser-extension test`：4 项文本输出测试通过。
- `pnpm --dir prototypes/browser-extension build`：最终独立构建及 TypeScript 通过。
- `pnpm --dir prototypes/browser-extension start`：最终构建服务运行于 3176 端口。
- 本轮文件的 Prettier、本地 Markdown 引用及 `git diff --check`。

应用内浏览器完成 **24 项新版检查**，实际结果见 [compact-checks.json](./compact-checks.json)：

- 默认面板 360px 宽、高度不超过 340px；六张图片时通过列表内部滚动控制高度。
- 多图上传、真实文件选择、复制格式菜单、设置切换和返回后队列保留。
- 网页右键 → 来源授权 → 小窗队列 → 上传结果；从设置视图进入网页演示后同样返回队列。
- 重复、上传失败、结果待核对、版本不可用、Token 失效和来源获取失败分别可操作；明确选择原图后才输出对应结果。
- 私有设置在上传前保留可见提示；深浅主题均已查看实际画面。
- 360／390／768／1440 视口无横向溢出，面板宽度始终不超过 360px。
- 长文件名保留完整 title；长站点地址不撑开设置，且可展开读取完整输入。
- 新版交互没有浏览器控制台警告或错误。

长地址检查发现设置网格曾被内容撑宽，导致控件被面板裁切；已使用明确的单列网格约束修复，并重新构建和复验。没有通过遮住内容或弱化断言来通过检查。

## 验证边界

这里验证的是独立网页原型。上传和授权仍为演示，未安装 Chrome／Edge 扩展，未连接真实 Ariso。原生系统图片剪贴板、物理文件拖入和系统剪贴板复制回读仍未验收；上一轮对应限制没有被本轮页面检查覆盖或改写。长文件名通过受控合成文件事件检查，不称作物理拖入。

真实长请求仍需由可持续打开的扩展页面承载，具体同尺寸小窗、失焦和关闭行为在正式扩展阶段验证；普通 action popup 关闭后继续上传不在本轮承诺中。没有运行整套主应用测试或本机 Docker／Colima，没有改动生产服务。
