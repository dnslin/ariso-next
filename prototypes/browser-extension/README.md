# Ariso 浏览器插件交互原型

- 日期：2026-10-25。
- 状态：根据用户“这个插件好大呀，一点都不简约”的反馈，改为约 360px 紧凑小窗原型。新版仍待体验；用户已授权的两类输入和[开发任务](../../tasks/browser-extension/todo.md)保留，正式扩展未实现。
- 依据：[浏览器插件方案](../../docs/specs/SPEC-browser-extension.md)、[设计交付规范](../../docs/design/handoff.md)。
- 范围：独立网页原型；不是已安装的浏览器扩展，不连接真实 Ariso，不上传文件，不验证或保存真实 Token。

## 打开体验

- [紧凑上传小窗](http://127.0.0.1:3176/)
- [网页图片右键演示](http://127.0.0.1:3176/?view=web)

建议依次体验：

1. 日常小窗只看 Ariso／设置图标、拖入／粘贴／选择、紧凑队列和上传／复制。没有大标题、全页导航、右侧设置栏或宣传说明卡。
2. 选择自己的本地图片，或通过原型演示工具加入示例图片；也可尝试拖入／主动粘贴。文件仅在本页预览。
3. 点击设置图标，查看连接、默认相册、标签、存储、链接版本和主题；设置后返回上传。只填写示例 Token，勿输入真实密钥。
4. 检查本次公开／私有状态后上传，观察传输、等待处理和完成的演示；公开结果可复制 URL、Markdown、HTML，私有结果说明需登录访问。
5. 切换到网页右键演示，在示例图片上右键选“保存到 Ariso”。来源授权后图片回到同一小窗队列，仍须手动开始上传。
6. 原型演示工具可切换首次连接、失效 Token、重复、上传失败、结果待核对、版本不可用和来源无法获取。切换后操作新图片查看对应状态；“重置演示”清空队列、配置草稿和异常状态。

演示场景等辅助控件不进入正式插件。网页、右键菜单和来源授权均为模拟，正式扩展将使用浏览器真实菜单与权限提示。

约 360px 是视觉方向，不代表普通 action popup 关闭后还能长上传。实际请求仍须由可持续打开的扩展页面承载，正式版建议使用同尺寸小窗；具体窗口方式、失焦、最小化和关闭行为在正式阶段验证，不新增公开轮询或后台保活。首版不承诺关闭窗口／浏览器后继续上传。

## 本地运行

复用仓库根目录已锁定的依赖，不另装 UI 库。使用 Node 24.x 和项目 pnpm：

```sh
pnpm --dir prototypes/browser-extension dev
pnpm --dir prototypes/browser-extension typecheck
pnpm --dir prototypes/browser-extension test
pnpm --dir prototypes/browser-extension build
pnpm --dir prototypes/browser-extension start
```

`dev` 和 `start` 均使用 3176 端口，只运行其中一个。构建和浏览器验证顺序执行，不在检查页面时覆盖构建产物。没有依赖新增；没有启动本机 Docker／Colima。

## 文件与验证

小窗、上传队列、设置视图、来源网页与结果反馈各自独立。样例图片和字体复用已有原型资产；真实文件预览使用本机 Blob URL，页面不会将文件内容发给服务器。

上一轮完整工作台的实际命令、26 项页面检查和截图保留在[历史验证记录](./evidence/verification.md)，不作为新版通过结论。紧凑版实际命令、24 项新版检查、截图和未验证项见[精简版验证](./evidence/compact-verification.md)。新版仍待用户体验，页面检查不等于真实扩展验收。

网页原型通过不代表 Chrome／Edge 已加载真实扩展，也不代表实际上传 API、浏览器域名授权、长上传生命周期或系统剪贴板已验收。
