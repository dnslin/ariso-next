## 历史与维护

[归档目录](./archive/README.md)保留 runtime 交付材料，以及准备阶段的早期原型、逐批补图、评审流水和检查证据。归档按材料是否仍作为当前入口区分，不表示其中全部事项已经验收。

PRD 保留已确认正文，不因目录整理修改需求。当前进度以计划及待验收清单为准；历史中的“下一份”“待补图”和旧分区名称只描述当时情况。业务规则以 PRD 和已评审规格为准；原型示例数据不能覆盖规则。

- 当前规则只在所属文档维护，其他文档通过链接引用。
- 阶段过程与逐批检查记录进入归档，原始 JSON、截图不改写；正文只维护当前结论与仍需完成的事项。
- 前端任务引用具体桌面、手机和状态节点；后置任务不能越过未完成的直接前置。
- 同步到 GitHub 后，执行状态以 GitHub 为准，本地维护任务定义、依赖和链接。当前尚未交付完整实施 Issue 和依赖自动检查。
- 移动文档时同步更新引用和配置，检查本地链接，不保留重复的当前版本。
