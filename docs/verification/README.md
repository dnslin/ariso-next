## 如何读报告

报告中的命令、环境、通过范围和未执行项是当次事实。默认全量、专项补验、设计对照、人工验收、CI 与正式发布分别说明；截图数量不代表业务覆盖。原始失败和后续成功各自保留，不因为阶段完成修改历史结果。

2026-10-17 已精炼历史原始产物。本地保留 Safari 最终矩阵与红绿证据、Favicon/水印正式 PR 记录与已提交最终证据、最近 UI/UX 和统计布局的最终代表、Runtime 基础最终证据；实际测试读取的生成 schema 已迁入 `tests/fixtures/api-key/`。其余已提交的逐轮截图、JSON 和日志改为固定提交链接，不保留重复副本。它们用于历史追溯，不自动成为后续每日检查门槛。当前维护从[验证指南](../guides/verification.md)选择适用入口，不逐个重跑历史命令。
