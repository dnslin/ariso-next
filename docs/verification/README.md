## 如何读报告

报告中的命令、环境、通过范围和未执行项是当次事实。默认全量、专项补验、设计对照、人工验收、CI 与正式发布分别说明；截图数量不代表业务覆盖。原始失败和后续成功各自保留，不因为阶段完成修改历史结果。

2026-10-17 已精炼历史原始产物。本地保留 Safari 最终矩阵与红绿证据、Favicon/水印真实输出、最近 UI/UX 和统计布局的最终代表、Runtime 基础最终证据，以及测试实际读取的生成 schema。其余已提交的逐轮截图、JSON 和日志改为固定提交链接，不保留重复副本。它们用于历史追溯，不自动成为后续每日检查门槛。当前维护从[执行约定](../tasks/execution.md)选择适用入口，不逐个重跑历史命令。

原始文件统一指向整理前提交 `edb097b1fd7396e2797aac2d04e826ab986062e2`。保留 JSON 中的截图路径和本机路径仍是当时快照；需要复现完整报告时在该提交查看整组产物，不把精炼后的本地目录当作原始完整报告。历史探针脚本保留供追溯，其依赖的旧原始文件需在对应提交中复现；当前迭代只使用[现行浏览器入口](../../e2e/runtime.md)。
