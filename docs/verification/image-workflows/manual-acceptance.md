# 四项图片功能人工验收

本轮修复尚未推送，完整浏览器验收与最新CI完成后再更新独立演示地址和验收提交。旧演示环境已为最终构建停止；当前尚未交付人工验收。原型、自动化检查、CI和本人工验收分别记录；以下项目等待用户确认。

- [ ] 批量打包：在图库选择两张图片，从操作栏的打包图标进入预检查，确认文件名、版本和总量；取消后，在选中图片上右键进入同一流程。实际下载ZIP，解包核对数量和内容。相册图片使用相同操作栏入口。
- [ ] 替换并保留外链：先复制一张测试图片的固定版本链接，再从详情的更多操作选择替换。选一张新图后立即开始，仍停留原详情，没有独立页、对比或再次确认；关闭详情后上传和处理继续，图库可以观察任务。派生全部完成前原链接仍读取旧内容。成功后原链接读取新内容，显示名称、公开性、相册与标签保持，旧临时分享失效。
- [ ] 私有单图临时分享：为私有图片创建1小时查看地址，用无痕窗口打开可免登录查看；普通私图地址仍需登录。撤销后再次打开分享应失效；重新创建使用新地址，旧地址不恢复。也可在分享管理中切换到私有图片分享进行管理。
- [ ] 多尺寸外链：详情复制链接中选择压缩图或水印图，再选择640/1280/1920最长边。首次明确生成后可复制URL、Markdown与HTML，界面展示实际输出。超过来源像素时不放大。替换后此前复制的尺寸链接保持不变并读取新内容。
- [ ] 手机与短屏：缩窄到手机宽度，检查完整表单可滚动、底部操作可达；390×400下ZIP文件清单仍可滚动读完首尾文件名。替换直接使用原详情，没有额外工作页或大段说明；关闭详情后图库仍可看到执行状态。
- [ ] 设置分类：基本设置、图片处理、账号与安全、上传API、邮件服务的桌面分类条外层与着色层16px、单项12px圆角一致；手机保持原选择器。未保存输入的离开提示、键盘焦点与导航顺序照常工作。

合并和部署需要用户另行授权，本轮不执行。
