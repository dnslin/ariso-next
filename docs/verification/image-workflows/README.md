## 实现范围

- 批量下载：图库及相册的操作栏图标、右键文字项进入同一预检查。冻结所选ID与版本，最多200项，明确排除不可用图片。Local/S3逐项读取，以STORE模式生成浏览器原生ZIP下载，不增加任务中心。
- 替换：在原存储创建独立候选，按各已发布角色自己的历史配方重建，并重建已有尺寸；原图、派生、尺寸、图片属性及元数据一次发布。失败继续提供旧内容，成功撤销旧临时分享。保留图片身份、名称、关系、创建时间和统计，不提供历史回滚。
- 单图临时分享：私有图片的免登录查看页，1小时/24小时/7天，默认24小时；每次资源请求验证授权，由Ariso转发，不跳转到独立S3签名地址。撤销、回收、转公开或成功替换使旧地址失效；重处理按原授权角色读取新内容。
- 尺寸预设：静态压缩/水印角色的640、1280、1920最长边，按比例缩小、不放大、不裁剪。首次明确生成后复制URL/Markdown/HTML；默认、原图和缩略图语义保留，已有尺寸URL在内容更新后保持稳定。

新增向前迁移0028/0029，包含五张表和内容更新时间。SQL已实际生成与审阅，未修改生产数据库。任务、存储、用量、清理和重启恢复复用既有机制。

## 实际功能覆盖

最终定向入口使用正式上传申请和multipart接收，并运行真实媒体工具。覆盖ZIP两个入口、版本冻结与明确排除、实际浏览器下载及解包字节；三个尺寸的真实像素与不放大、常显格式及完整链接；临时分享的选择期限、创建/复制/预览、无所有者Cookie的查看、普通私图401、撤销410与新建不复活旧Token；替换保留身份/关系/外链、实际新字节、已有尺寸更新、旧分享失效及管理预览更新。

接收中返回场景真实暂停一个multipart请求：进入工作页后返回详情和图库，观察共享活动任务；释放实际剩余字节，等待同一任务完成，核对缩略图内容标识和实际解码更新。它是受控时序夹具，不是实际网络故障事故。

匿名检查使用同一Ego浏览器配置文件中的独立localhost子域名，实际确认session为空；它不等于独立浏览器配置文件。分享表单的自动场景使用真实Tab/方向键/Enter；Ego部分指针操作错误判定disabled，未作为指针通过。独立IAB的真实鼠标选择期限、创建、撤销和替换已验证，见[设计与消费路由对照](./design-comparison.md)。

## 收尾修正

- 接收恢复移到接受新请求之前，避免启动恢复误取消新请求；重启检查通过。永久删除先清理自有接收临时目录，再删记录，真实失败保留诊断并可重试。
- 当前已发布水印角色保留其配方素材；角色重处理到新素材或删除后释放旧素材。旧配方中无关、已删除的水印不阻止替换其它角色。
- 尺寸临时目录复用任务根标记；取消是正常状态，真正磁盘/退出清理错误继续记录。Node24纯类型剥离不支持的参数属性已改为等价字段赋值。
- 替换预算的动态路径表达式曾使Turbopack错误追踪54份媒体源码；改为既有根目录拼接后追踪精确减少54项，未放宽产物断言或增加排除规则。
- 启动/密钥检查夹具使用完整正式SQL前缀，再叠加原故障迁移；保留精确表清单、回滚、拒绝旧产物及密钥恢复断言。旧列升级夹具另核对新内容时间为空。
- 替换任务回读确认后清理旧传输错误，终态清理旧进度消息；未发现新任务时保留不确定性，真实job.error仍显示。管理预览随contentId更新，外链保持稳定；回收预览允许该内部内容参数，仍保留原权限及其它参数限制。
- 分享地址同步自动全选导致重复Tab时焦点留在屏外，已通过实际对照定位并去除；保留手动复制失败后的显式选中。替换返回详情的两个焦点路径现均返回更多操作；上传上下文也实际核对。
- ZIP短屏原先可将清单压至细线，Body现保留内容行本征高度并滚动。新增实际清单高度、首尾文件行可见与完整文本、固定按钮的回归；最终390×400清单175px，下载按钮112×44px。
