## 回写结果

原位更新图片模式临时、已采用、读取失败业务卡及既有临时/到期说明代表。关闭与文字基准整页 `34:338` / `60:686` / `102:1526` / `102:2120` 没有素材 ID，保持无清空入口；读回其 clearCount 均为 0。保留 ID 的关闭/文字变体仅放入本任务已有补充 section。

清空后的完整图片模式卡没有 ID 属性卡，也没有清空按钮；仍保留上传入口、参数和共同说明。卡片外的设计注释明确：清空只把 `watermarkAssetId` 改为 `null`；图片模式保存仍需素材；关闭/文字模式可以保存 `null`。保存后解除设置引用不表示素材字节立即删除。中性反馈和焦点回固定保存按钮、保留滚动位置是交互要求，静态 Figma 不声称已验证运行时行为。
