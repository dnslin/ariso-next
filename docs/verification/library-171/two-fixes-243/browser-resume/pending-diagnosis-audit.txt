只读最小修正研究（未实施，等待新增范围决定）
1. 当前 HeroUI Dialog 的运行时代码会将 ref 放在 ...props 中交给 RAC，但其公开类型 AlertDialogDialogProps 未包括 RAC 组件额外的 RefAttributes。不能将顶层回调 ref 称为当前 HeroUI 的受支持类型接口，也不应为它增加类型强制转换或依赖补丁。
2. RAC Dialog.mjs:122–126 的默认根是 section，RefAttributes 类型为 HTMLElement。把它描述为 HTMLDivElement 与实际元素不符。虽然运行时 callback ref 可到达根节点，声明式属性映射更直接，不需要依赖 ref 回调重触发来同步 pending。
3. 已有受支持 API 是 render。DialogProps 明确继承 DOMRenderProps<'section',undefined>。其类型和文档在 /Users/dnslin/.codex/worktrees/issue-148-sharing-experiment/ariso/node_modules/.pnpm/react-aria-components@1.21.1_react-dom@19.3.0_react@19.3.0__react@19.3.0/node_modules/react-aria-components/dist/types/src/utils.d.ts:193–208，要求只渲染同一种根元素，并透传 props/ref。
4. 实现依据是 /Users/dnslin/.codex/worktrees/issue-148-sharing-experiment/ariso/node_modules/.pnpm/react-aria-components@1.21.1_react-dom@19.3.0_react@19.3.0__react@19.3.0/node_modules/react-aria-components/dist/private/utils.mjs:156–177：dom.section 将全部已计算 DOM props、children 与合并后的内部 ref 交给 render 回调。
5. 推荐最小表达为 render={(domProps) => <section {...domProps} aria-busy={controls.pending} />}，替换当前无效的顶层 aria-busy。此方案保留原 section、role、aria 标签、样式、事件、子树及内部 ref；没有额外 wrapper、effect、fallback 或新依赖。它会随当前 pending 的正常渲染声明式更新属性。
