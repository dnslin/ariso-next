# 相册真实组件过渡示例

2026-10-12。本轮只重做 `/albums` 列表，不代表全站动画已经交付。按用户反馈取消淡出，并放慢进入节奏：卡片和空状态直接移除，切页直接切换；保留进入与列表补位。上一轮新增的通用骨架格已撤回，其他业务页面保持本轮动效修改前的实现。

## 参考与选择

参考 [Motion](https://github.com/motiondivision/motion)、[React Spring](https://github.com/pmndrs/react-spring) 与 [React Transition Group](https://github.com/reactjs/react-transition-group) 的真实组件生命周期和列表过渡方式。当前使用锁定版本 Motion 14.1.0，只负责进入和位置变化。不再需要退出等待和路由快照，因此删除 `AnimatePresence`、`next-view-transitions` 依赖及对应路由接入、原生快照样式。

## 当前行为

- 标题、工具栏和卡片各自进入。透明度匀速显现 420ms，同时从下方 10px 归位，位置过渡 480ms。卡片错峰 55ms，最多延迟 165ms。原先的 200ms 强缓出让透明度过早接近完成，因此改为透明度与位置分别计时。
- 搜索和分页请求期间保留真实旧卡片，并标记忙碌；不插入骨架格。
- 结果返回后移除不匹配卡片，不降低其透明度，不等待退出。保留项不重复淡入，在 240ms 内平滑补位。
- 切页直接切换，没有淡出、退出位移或原生路由快照。返回后真实卡片仍有进入动画。
- 减少动态效果时取消位移、重排和错峰，保留 200ms 淡入；系统偏好变化可实时生效。
- 空状态仅保留 300ms 匀速淡入，无退出动画或额外等待。菜单继续使用 HeroUI；右键定位锚点放在 body，避免卡片移动期间坐标偏移。

本轮新增逐帧节奏断言：正常模式下每张真实卡片从透明度 0.1 到 0.9 的可见过程至少 250ms，至少有 8 帧中间状态；首次进入和返回均检查。12 个实际可见窗口为 315.1–333.8ms，每个包含 20–21 帧中间状态。初跑右键菜单检查因低层鼠标事件未稳定转移焦点而超时；改用浏览器完整右键操作，并等待菜单获焦后重跑，通过原有菜单坐标及焦点恢复断言。
