# 三页组件与多选上传修正

2026-09-27；延续 [Issue #85](https://github.com/dnslin/ariso-next/issues/85) / [草稿 PR #126](https://github.com/dnslin/ariso-next/pull/126)。用户针对图库详情、回收站与上传三页追加截图反馈，要求固定预览、持续动效、多选与继续添加，并使用现有 HeroUI 组件。执行与设计规则仍在[任务执行约定](../../../tasks/execution.md)和[设计交接](../../../design/handoff.md)，未改冻结 PRD 或既有需求编号。

## 实际变更

- 原图、压缩图、缩略图共用按原图尺寸建立的透明预览舞台。删除条件性 footer 提示对正文高度的挤压；原图隐私说明放进 Popover，手机通过权限说明读取。真实图片加载前显示同尺寸 Skeleton，读取失败仍显示错误占位。
- 弹窗使用 CloseButton；记录导航仍为“返回”。公开／私有／管理员权限使用 Chip + Popover。复制格式使用 ButtonGroup，详情和队列操作使用 Toolbar，简短说明使用 Tooltip。复制、下载发起和回收／正常恢复用 Toast，存储停用和未知结果等需要处理的提示保留。
- 上传内容铺满工作区，右侧设置 360px、间距 24px。选图后左列成为队列，可一次多选及继续添加。空态云图标持续 2.8s 轻微浮动；减少动态效果时静止。手机队列在前、设置在后，底栏继续添加／开始上传始终可达。
- 一次开始以一份 submission 和处理快照提交所有尚未开始的文件，按真实 batchSize 分组；全页同时最多传输 3 个文件。后续追加项等待下次开始，当前设置修改不改变已提交内容。查询、取消、移除和资源释放均按文件执行；清空结果不删除服务端图片。

没有新增依赖或数据库迁移。仍仅覆盖已实现的本地 JPEG／PNG，不将多选描述成完整上传任务组已完成。拖放、全格式、S3、相册／标签批次选项、Lightbox、版本管理、永久删除等继续由既有 T-UP-03/07、T-LIB-04/05/11 等任务承接。本轮未增加手动主题切换，主题仍随系统。
