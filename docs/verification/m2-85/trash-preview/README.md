# 管理员回收站预览

2026-09-27；#85 / PR #126 人工验收后的明确变更。用户要求登录管理员在回收站看到缩略图，并接受记录详情预览；原“不显示图片内容”设计由此授权覆盖。冻结 PRD 与 Figma 保留原文，现行约定在 handoff、library、delivery、media 规格中更新。

## 实现

- 回收列表显示实际保存的缩略图，记录详情复用图库 `PreviewImage` 展示可用版本，不增加复制、下载或版本选择入口。
- `GET/HEAD /api/trash/{id}/preview?type=...` 复用既有流传输，仅有效所有者会话可读当前回收且存储启用、未进入永久删除的已保存版本。响应 no-store，不记公开访问量。原 `/i` 所有版本仍拒绝回收图片。
- 失败图片已有版本可以预览；停用、删除中、清理失败及无缩略图显示原因。实际读取失败保留错误；成功刷新列表后重试相同图片 URL。
- 刷新入口移至标题右侧，使用 44px 图标按钮和 Tooltip；返回入口统一圆角与内边距。公共外壳保持复用。
