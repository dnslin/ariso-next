# 移除两处说明入口

2026-09-27，Issue #85 / 草稿 PR #126 的人工反馈。用户明确要求删除截图中的回收站管理说明和原图信息按钮，本轮不新增功能或改权限契约。

## 实现范围

- 回收站列表、回收记录移除“仅管理员可见”Chip及其Popover，标题不留空占位。
- 图库详情移除原图旁的信息按钮、GPS说明及其44px占位。四个版本标签等宽，仍支持原有键盘切换与禁用状态。
- 图库公开／私有标签和访问说明保留。回收预览仍须管理员登录，原外链仍拒绝回收图片。
- 删除不再使用的原图Popover及图标引用、管理员标签特例；不添加替代提示或依赖。

当前设计约定已更新至[handoff](../../../design/handoff.md)。此前[页面切换与七项反馈](../workspace-continuity/README.md)中的这两处说明设计由本次明确要求覆盖，其余结论和历史证据保留。

## 版本切换闪动修复

后续人工反馈“图片详情切换图片区域闪一下”已定位为标签切换重新挂载预览，缓存图片也短暂进入Skeleton。采用现有HeroUI／React Aria的`shouldForceMount`保留已访问版本，非活动面板`inert`且隐藏。未访问版本不提前请求，关闭详情释放面板；首次下载新版本仍显示加载提示。布局和Figma节点未变。
