上传最大内容宽1200；1440画板实际1144=760+24+360，上传选择区高360、设置区宽360。手机358宽堆叠、选择区高280。第一次截图发现上传设置被挤出，已修正父容器HUG为固定/FILL组合，最终截图无裁切。

## 自检与实施边界

已实际查看以上19张最终Figma截图，检查整页、公共区域、并排与手机上下、图片比例、说明浮层、底栏边距。上传首次裁切已修正后重截。展开浮层覆盖下方内容属于按需显示，收起主态无常驻大说明。字体来源回读为Noto Sans SC/Caveat/Inter，未替换为默认字体。

原型保留的多选、相册标签、搜索批量、大图、版本信息等仍按既有任务边界；本次不因此新增未实现功能。回收底部明确为本次已实现的恢复图片。用户此前八类差异不因本次设计编辑自动消失，实际改动后的独立浏览器复验及用户人工验收仍待完成。
