# 用户批准的后台界面精简

2026-09-27；延续 [Issue #85](https://github.com/dnslin/ariso-next/issues/85) / [草稿 PR #126](https://github.com/dnslin/ariso-next/pull/126)。用户提供四张标注截图，并在实施计划后确认“可以 就这么办”，授权本次界面调整和 Figma 同步。规则仍统一维护在[设计交接](../../../design/handoff.md#后台界面精简2026-09-27用户批准)与[执行约定](../../../tasks/execution.md)，未改冻结 PRD、需求编号、数据库或内容访问契约。

## 实施结果

- 图库与回收预览取消有色底板，完整保留图片比例。图库桌面图片随正文可用高度缩小；极短窗口保留可识别尺寸和正文滚动。回收详情桌面图文并排，手机上下排列。
- 版本切换使用 8px 圆角和黄色选中态。可见返回文字统一为“返回”，可访问名称保留目的地；回收详情移除底部重复返回。
- 公开、私有与仅管理员可见成为可点击说明入口。复用 HeroUI Popover，支持键盘展开、Escape 关闭及焦点归还。必要错误仍直接显示，原图下载的隐私提醒贴近动作。
- 首次进入回收站不再强制聚焦标题。从记录返回定位重新挂载的来源记录；恢复后来源不存在时回到列表标题。
- 移除没有真实层级的“工作空间”面包屑。共用底栏背景与边线铺满工作区，内部保留正常边距和安全区。
- 上传区域最大 1200px，桌面设置列 360px、间隔 24px，两卡最低 360px；手机选择区最低 280px、设置自然堆叠。精细指针悬停时云图标上移 4px；上传中轻微透明度变化，成功显示完成图标，遵守减少动态效果设置。

继续复用统一外壳、Lucide 图标和现有 HeroUI 控件。没有增加依赖或模拟多选、拖放、大图、筛选、批量、永久删除等后续能力。主题继续跟随系统，本轮没有增加手动主题切换。
