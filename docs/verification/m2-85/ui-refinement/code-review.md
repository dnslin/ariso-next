## 发现

- **已修复：访问说明按钮必须保留当前可见性。** `AccessDisclosure` 的公开/私有按钮可见文字为当前权限，但 `aria-label="查看访问说明"` 覆盖它，屏幕阅读器无法从按钮得知“公开/私有”，语音按可见文字定位也失配。当前名称已改为 `${label}：查看访问说明`，浏览器断言核对实际可见 label 与完整名称。回收站“仅管理员可见”没有这一问题。
- **已修复且最终浏览器回归通过：从回收记录返回需定位重新挂载的来源记录。** 切入详情时列表分支卸载，`trigger.current` 指向的旧 DOM 断开。返回时列表创建新 DOM，`isConnected` 检查必然失败，当前实现回退到标题，不能满足新增测试要求的原记录回焦。当前已保存 `triggerId`，返回时按记录 id 查询新 DOM，找不到才回标题。已读取实际红证据 `focus-red.json`：旧行为把焦点落在 `trash-title`，未伪造原问题。
- **已修复且最终浏览器回归通过：桌面短视口预览高度。** 已为容器计算添加 `max(160px, ...)` 下限，避免内容区过短时图片压为零。新增 400px / 320px 高度测试检查图片宽高非零、内容区可滚动，以及滚动后可见完整预览底部，最后恢复原视口。

- 版本控件仍为 HeroUI Tabs，选中键、Tab/Panel 对应关系和未保存/不可用禁用逻辑保留；只调整视觉而未改成普通按钮。
- 返回可见文字精简为“返回”，保留去向特定的 `aria-label`。回收详情尚未取得记录时仍有可用返回动作。
- 共用外壳移除面包屑后，真实 upload/library/trash 消费路由均进入验证。底栏改内边距而非外边距，保留安全区 padding，背景可延伸至工作区边缘。
