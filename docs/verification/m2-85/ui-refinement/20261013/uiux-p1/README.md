用户在审阅 [交互原型](../../../../../../design-plans/uiux-review-20261013/p1-prototype/README.md)后，于 2026-10-13 明确要求“按照这个去实施”。实施基于优化方案，限定 F01–F04；不实施 P2，不改变既有业务定位、保存契约或已接受的动画。

## 产品对照

| 范围         | 实施                                                                                   | 复用与边界                                                                                                                                   |

四项均沿用现有 UI 家族及 [设计交付规范](../../../../../design/handoff.md)中的品牌、主题、布局、固定底栏和图标来源。批准原型是本轮新增交互的对照依据；未修改 Figma。不复制样例数量或自动成功，所有提交和对象跳转使用真实业务数据。

实际操作核对后，“修改”立即滚动到上传设置并聚焦，避免长距离平滑滚动干扰随后的下拉选择。单个删除清理任务直接进入对应回收记录；只有多个任务才展开选择，以便准确定位对象。两处均保持原型的操作意图，不增加确认步骤。
