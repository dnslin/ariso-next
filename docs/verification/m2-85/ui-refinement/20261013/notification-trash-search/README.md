# 通知、回收站、搜索与分享状态修订

本轮按[修订计划](https://github.com/dnslin/ariso-next/blob/edb097b1fd7396e2797aac2d04e826ab986062e2/design-plans/uiux-review-20261013/notification-trash-search-plan.md)实施，保持既有业务流程与 HeroUI 组件。对话框排查后，只把纯成功告知改成 Toast：相册编辑／删除，以及单张图片永久删除。创建、确认、失败、未知结果和批量逐项结果仍保留可操作的界面。

设计文件：[Ariso Figma](https://www.figma.com/design/74sT9Hrf8G4czcWeTkET5b)。Figma 中本轮新增的 12 张桌面／手机修订画板为可编辑 FRAME；图库和回收站等 5 张既有搜索画板直接更新了框内放大镜。网页[交互原型](http://127.0.0.1:61514/trash?flow=cleanup&mode=after)复用正式回收站组件，桌面／手机真实 Chromium 检查 19 项通过，包含确认、结果、状态与短视口。

## 验证与边界

本轮浏览器使用隔离样例数据库、Ego TaskSpace 29。分享状态／刷新图标、图库与回收站搜索、回收站确认／结果／单图清理及原核对场景均通过，原始报告见[可下载报告包](https://github.com/dnslin/ariso-next/blob/edb097b1fd7396e2797aac2d04e826ab986062e2/docs/verification/m2-85/ui-refinement/20261013/notification-trash-search/evidence/browser-reports.tar.gz)。其中 `albums-browser.json` 通过 9 项流程检查及 70 组布局检查，覆盖编辑与删除 Toast、手机和桌面布局，以及原有表单、失败和列表流程。原测试把保留旧列表的刷新误判为必须出现加载占位；已改为核对旧列表在新请求期间保持可见，且容器标记忙碌。

本地环境为 macOS ARM64、Node 24.18.1、pnpm 11.19.0。实际运行 `pnpm install --frozen-lockfile`、`pnpm run format:check`、`pnpm run lint`、`pnpm run typecheck`、`pnpm run test:unit`、`pnpm run build`、`pnpm run test:integration --maxWorkers=4`、`node docs/tasks/check.mjs`。安装、格式、静态检查和构建最终退出码均为 0；单元 193 个文件／2368 项通过，集成 191 个文件／1898 项通过，任务文档检查 120 个任务／298 项需求通过。构建仍打印其他平台可选依赖与 `@opentelemetry/api` 的追踪告警，最终退出码为 0。

实际运行的浏览器定向入口：`--suite=sharing-management --only=representative`、`--suite=trash --only=representative`、`--only=confirmation`、`--only=approved-results`、`--only=cleanup`、`--only=review-fixes`、`--only=approved-query`、`--suite=collection-shortcuts --only=menus` 与 `--suite=albums`，最终均退出码 0。报告包包含分享、回收站确认／结果／单图清理／搜索、图库菜单和相册等 10 份原始 JSON；同目录截图与上表保留逐项设计对照。

相册套件还暴露一个独立边界：长度达到 100 个 emoji 的相册名会让图库筛选控件生成的隐藏原生选项撑宽手机布局。它不是本轮 Toast 改动造成的；本轮未修改该控件，后续应单独修复并回归。

本地预览使用独立样例数据：[回收站](http://127.0.0.1:3110/trash)、[分享](http://127.0.0.1:3110/shares)、[相册](http://127.0.0.1:3110/albums)。预览的健康检查、真实登录和会话读取通过；它与原 3109 预览分开。正式产品、远端服务和发布环境未在本轮验收。
