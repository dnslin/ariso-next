## 已发现并处理的问题

1. **Required，已修正：当前生效状态误用已保存凭据。** 初稿在 `effective.enabled=false` 时以 `saved.clientId/hasSecret` 判断“尚未配置”。保存清除密钥但尚未重启时，这会把仍完整的停用生效配置说成“当前生效：尚未配置”。实现已改为待重启时明确显示“当前生效：未启用”，普通判断使用 `effective` 字段；新增真实组件渲染测试覆盖 `saved` 已清空、`effective` 仍完整且停用的场景。
2. **Required，已补充：新 Accordion 行为不能只检查入口文字。** 默认 OAuth 布局场景现在通过真实 GET 读取公开配置快照，键盘展开并逐项比较 saved/effective 的启用状态、Client ID 和密钥是否已设置，断言可见性与 `aria-expanded`，采集展开截图，折叠后检查同页、焦点与滚动。场景代码已审查；本轮浏览器尚未执行。
3. **测试修正，已处理：滚动基准应在键盘聚焦入口后采集。** 聚焦屏幕下方入口的正常浏览器滚动不能被误报为展开/折叠改变来源位置。实现已将基准移到 `page.focus` 之后，保留对展开/折叠本身的滚动断言。

## 代码结论

- **正确性与边界：** 未配置时只提供可执行的配置入口；配置实际启用后提供绑定。已有绑定在停用登录后保留，并继续允许解绑。配置读取失败或加载不阻塞独立、已核对的解绑；绑定读取失败或加载不阻塞配置。保存/解绑结果未知时隐藏重复写操作，只保留 GET 核对，失败保留错误和上次读取说明，不把连接中断当作未写入。
- **焦点与生命周期：** 弹窗正常关闭沿用 HeroUI 焦点恢复；未知结果关闭后原有视图钩子仍能聚焦新的页面核对按钮。成功解绑原有处理仍选择可用绑定/配置入口，缺少入口时回到可聚焦标题。两个查询、重定向恢复监听、卸载保护与秘密草稿生命周期没有改变，也没有新增 effect 或持久化完整对象。
- **职责与简单性：** 设置行只复用本页实际重复的四行布局；状态组件负责值，账号区域组合相应操作，请求与变更规则仍在现有模块。两组按钮分支对应实际加载、错误、未知和可操作状态，没有引入状态框架、兼容层或假设性抽象。没有必须继续拆分或增加通用层的结构问题。
- **共享界面：** 选中背景改由实际 Tab 承载，删除可能覆盖文字的 Indicator 和其过时背景规则。图片处理、账号、上传 API 三个已实现消费路由仍使用同一组件；既有消费者场景新增计算样式与 Indicator 缺席断言，两端及浅深主题的真实复验仍未执行。
- **安全与性能：** 本轮不更改服务端、OAuth 契约、鉴权或密钥保存方式。摘要只显示公开 Client ID 与 `hasSecret`，不会显示秘密原文。使用组件独立导入与现有图标库；渲染期间直接派生小型状态，没有新增请求串行、重复缓存或大型快照。
