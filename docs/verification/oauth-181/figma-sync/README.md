## 图层与原有设计边界

读取并复用了现有 Button/Primary、Button/Outline、Input、Ariso/Switch、Sharing/IconButton 和 Sharing/NeutralToast。新增文本使用项目 Noto Sans SC。颜色绑定既有 background、surface、foreground、muted-foreground、accent、destructive、primary、primary-foreground 变量；浅深色模式沿用原集合。

没有修改 Figma 公共组件、全局变量、公共 shell、站点设置分类或冻结 PRD。原账号页的 shell、导航、分类和所有者信息承袭原设计。原业务 root 编号保留，较长的来源页面状态移到独立补充区域，避免与原画布相邻状态重叠。

所有同步界面由可编辑文本、组件实例、Auto Layout 容器和矢量图标组成。只读查询确认 38 个主要 root 内没有 IMAGE fill。PNG 文件仅是核对证据，没有回填为设计图层。

## 关闭浮层后的未知状态约定

- 保存未知的来源页面：D 814:14898、M 814:29892。关闭配置浮层后仍显示保存结果待核对、“上次读取”的生效值和“重新核对配置”。绑定写入与“登录配置”入口均不可用。先 GET 核对成功，再重新打开配置并建立 Secret 为空的新草稿。D 814:15437、M 814:30245 保留为当前打开配置期间发生结果未知的状态；该框暂不可修改字段、开关或清除 Secret，主要操作为重新核对配置。
