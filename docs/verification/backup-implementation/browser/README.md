# 正式备份恢复浏览器与设计对照

执行日期：2026-10-22 至 23。Node 24.18.1、pnpm 11.19.0、Ego Lite Chromium。只操作本任务创建的 TaskSpace 5，未操作用户原型空间。

## 实际运行

```sh
EGO_TASK_SPACE=5 EGO_PAGE_LABEL=p1 \
BROWSER_REPORT_DIR=.data/backup-browser-keyboard-final \
pnpm run test:browser -- --suite backup
```

命令退出 0。入口先构建独立外壳和 UI 测试夹具，再调用正式浏览器运行器。最初因独立 UI 夹具未安装依赖而失败，补做 `pnpm --dir tests/experiments/ui install --frozen-lockfile` 与该夹具的 `typecheck` 后重跑；没有跳过前置构建。

使用真实 standalone 服务、临时独立 DATA_DIR 与测试账号。创建、下载、恢复、重启后验证四阶段全部通过；备份从浏览器原生附件下载到本地，检查 age 文件头。随后源服务停止并删除整个源 DATA_DIR，目标只用这份文件恢复。原密码登录、两张图片实际显示、原图读取、相册与标签关系均通过。初始化码、密码没有写入 URL 或浏览器持久存储。刷新需重新输入当前初始化码，ready 状态可续接。运行器最终关闭服务并删除临时数据。

暂停窗口由一个真实已准入上传请求保持。图库图片可浏览、复制链接可用，添加相册和标签禁用；上传不可开始，公开原图仍返回 200；释放原上传后备份完成并恢复修改。图库与上传页面都实际操作，未用原型计时器制造暂停或成功。

## 视口、主题与键盘

12 个状态分别检查 1440×1080、390×844、360×780、430×932、768×1024、390×560，每个视口覆盖浅深色，共 144 组截图及几何检查。全部无文档、主区域或表单横向溢出。手机/平板点击目标至少 44px，桌面至少 24px；使用浏览器 1/64 CSS 像素精度比较。四阶段捕获的未处理浏览器错误均为空。测试使用减少动态效果，并在截图前等待有限动画结束。

键盘检查实际先失败：从初始化码按 Tab 会落入裁剪隐藏的原生文件输入。为该输入设置 `tabIndex=-1`，保留可见文件选择按钮。最终实际按 Tab 依次进入文件选择按钮、密码输入；390×560 下密码完整显示在固定底栏上方，断言通过。创建备份的空输入检查也实际验证焦点回到密码字段。

六个真实设置页面逐一检查了分类顺序、当前项、后台导航、品牌与账号入口，见 [settings-consumers.json](settings-consumers.json)。矩阵及结果摘要见 [summary.json](summary.json)。完整原始截图和逐项控件几何记录保留在任务本地 `.data/backup-browser-keyboard-final/`，未把所有 144 张都声明为逐张目视验收。

## 边界

本记录是代理执行的自动流程和代表性设计对照，不替代用户最终人工验收。没有真实手机软键盘、非零安全区或其它浏览器实测；项目已取消这些物理设备门槛。本轮没有 S3、发布、生产部署或完整十万对象应用容量验收。真实字节、素材与密钥转换详见 [HTTP 记录](../production-http.md)，容器另见[ARM64 记录](../container/README.md)。
