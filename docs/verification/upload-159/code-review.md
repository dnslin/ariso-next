## 初审 Required 的处理

初审发现 `e2e/upload-input.mjs` 只对输入控件提供的原始 File 建立 WeakRef。`controller.add` 会重包 File，所以原始对象被回收不足以证明 Uppy 实际拥有的文件已释放。

最终复读确认：新增脚本在 `URL.createObjectURL(file)` 处跟踪同一个实际队列预览 File，并断言观察器确实收到过对象；清除后同时断言原始 File、队列预览 File、URL 和两个输入控件均已释放。旧 `e2e/upload.mjs` 也补充了重包对象跟踪。本问题的测试实现已修复，没有通过删除断言或弱化检查解决。

该直接 GC 观察覆盖有本地预览的队列 File，包括 PNG 大队列。HEIC/SVG 等无预览包装 File 没有同样的直接 GC 观察；记录已明确此限制。最终诊断报告记录实际队列 PNG File、原始输入 File 和 URL 清理断言通过。这是诊断输入路径的结果，不代表原生文件夹选择或完整浏览器套件通过。
