精简[最终证据](evidence.json)保留版本、镜像摘要、发布验证摘要、前后日志及线上检查结果，不保留逐轮转换图片和重复报告。

普通切页在旧版本轮未稳定复现错误，因此用首块读取后断开连接作确定对照。DOM 中未完成的图片数不能直接视为网络取消数。验证 GET 可能增加访问统计；未新增业务上传、删除图片或破坏线上文件来注入磁盘故障。真实 EIO、无关 AbortError 及取消竞态的日志保留由已通过的集成回归覆盖。

修复前新增取消断言有 6 项失败，旧 standalone 的真实 HTTP 断开用例也失败；修复后本地 2423 项单元、1740 项集成与媒体测试通过，独立复审通过。实际运行了冻结安装、lint、format:check、typecheck、openapi:check、build、test:unit 和 test:integration。该记录只证明当次发布与专项验证，不代表全站浏览器或手机实机验收；本次归档未重复执行产品测试或部署。

归档后已清理本轮发布、调试目录及可再生成的 `.next/`、`dist/`、类型缓存和两份测试日志，共 6948 个文件、约 739 MiB。关键证据保留在本目录，线上持久卷和升级备份保留；当前测试源码、夹具及依赖未变。
