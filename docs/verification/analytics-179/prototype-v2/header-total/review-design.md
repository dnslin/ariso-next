# Issue #179 累计访问头部布局与数字滚动独立设计复审

当前结论：本轮累计访问头部布局与数字滚动通过独立视觉提案复审，无剩余阻断视觉项。已实际查看13张截图并只读原型动效记录。本次只审独立设计原型；整版方案尚未获用户批准，不代表产品实施或 UI 人工验收完成。

## 依据与范围

评审者实际查看用户附件 `codex-clipboard-7847124e-eb3b-43f2-ae72-b4973b12d6ba.png`：红框标出正文累计访问，箭头指向头部右侧、关闭左方。本轮以该图与用户“移到头部右侧、关闭左方，并加数字滚动”的明确要求优先。现行 [handoff](../../../../design/handoff.md)、本轮已实读 Figma 公共外壳 / 正常统计节点及 [前轮反馈复审](../feedback/review-design.md)继续作为主题、控件、圆角与响应式基准；没有对应的新头部 Figma 节点，不虚称新方案已同步或已经逐像素还原。

沿已读 `frontend-design`、`emil-design-eng` 与 Figma 技能审查层级、密度和短促动效。实际只读 `page.tsx`、`style.css` 的本轮 diff、新增 `rolling-number.tsx`，核对已安装 HeroUI 样式中 `--ease-out-quint` 的真实定义。未操作浏览器、未修改产品、原型或 Figma，仅写本报告。

## 实际截图与动效记录

先核对整页与公共区域，再看头部、图表及控件。[桌面1440×1080](./desktop.png)、[手机390×844](./mobile.png)、[窄手机360×844](./mobile-360.png)、[手机深色](./mobile-dark.png)和[平板768×1024](./tablet.png)的可见公共外壳未出现新的排列变化。桌面及平板累计位于身份右方、关闭左方，符合用户箭头方向；手机沿相同头部层级分成两行，没有将正文缩成桌面比例。

实际查看 [长名桌面](./long-name-desktop.png)及[长名手机](./long-name-mobile.png)：样例“沿海公路的清晨与远处的灯塔”完整可读，累计1,100与关闭并存，不相互遮挡。正常累计1,248的逗号留在数字之间，单位“次”与数字基线协调；累计只有头部一处，正文直接开始三版本横条，未重复标题或数值。

实际查看 [滚动中间帧](./rolling-midpoint.png)：相邻数字的局部笔画属于逐位滚动过程，限于单行插槽，没有伸入累计标签或越过头部；千分位逗号和单位保持静态。稳定态图显示完整1,248，没有持续残影或多行数字。[browser.json](./browser.json)记录4条原生数字 transform 过渡，duration均280ms、easing均为 `cubic-bezier(0.23, 1, 0.32, 1)`；辅助阅读名称在过渡期间即为完整最终值1,248，不朗读中间数字。评审者只读此运行记录，没有亲自执行或播放浏览器动画；静态中间帧与记录相符，但不把单张图称作完整动画录像。

[减少动态效果图](./reduced-motion-mobile.png)布局与正常手机相同，完整最终值清楚；对应原型记录各数字transition-duration均0s、running为0。[零值深色](./zero-mobile-dark.png)仅显示0，三版本与三周期均为0；[旧值手机](./stale-mobile.png)保留累计1,248，同时正文明确刷新失败及上次更新时间，不把旧值作为刚更新成功。加载 / 首读错误 / 不存在隐藏累计由源码和原型行为记录核对，本轮未另拍三态，不虚称逐图视觉审查。

[390×400首屏](./short-mobile.png)及[滚动底部](./short-bottom.png)显示：头部累计、身份和关闭固定可见；正文可滚至三个周期标签末端，底部工具仍可用。短视口正文空间较少，图表分段滚动阅读，没有裁掉退出入口或永久藏住末端内容。原型演示状态选择器属于测试工具，不记作产品业务控件。
