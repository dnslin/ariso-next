## 本轮变化及依据

桌面身份、累计、关闭采用三列；手机身份和关闭在首行，累计标签及数字在第二行两端。正文直接从访问版本图表开始，不重复累计。累计口径复用 HeroUI Popover、关闭复用既有44px控件，圆角与公共区域沿项目 handoff。新位置以用户附件箭头为准；既有 Figma `451:3748/8551`、`446:8063/8030`、`102:3228` 已在本任务实读，未宣称新头部具有获批节点。

实际使用 animate 指导短促数字变化、emil-design-eng 核对层级和手机布局、vercel-react-best-practices 避免冗余状态和逐帧渲染、ego-browser 检查真实页面。已检查现有依赖及 HeroUI 本地主题定义，无新增依赖。数字逐位以原生 transform transition 滚动280ms，使用 HeroUI `--ease-out-quint`；千分位和单位保持静态。组件不保存前值、不用计时器或逐帧 React 更新。辅助名称即时提供完整最终数值；减少动态效果模式直接显示最终值。零值显示0，加载、首次错误及图片不存在不伪造累计。
