外层role=img/aria-label为当前完整格式化数值，内部全部轨道aria-hidden，辅助阅读不会读出每格0–9或动画中间的拼接数字。单位“次”和“累计访问”仍为相邻可读文字。没有新增live轮询播报。动画期间视觉中间帧属于用户要求的滚动效果，不能把屏幕阅读名称延迟至动画结束。

### 性能、可中断性与减少动态效果

`style.css:504-517`只transition transform，280ms低于技能300ms预算；已实际检查固定HeroUI theme的`--ease-out-quint`为`cubic-bezier(0.23,1,0.32,1)`，与STANDARDS推荐strong ease-out一致，不是未定义变量。偏移变量仅设在轨道自身，每次值更新一次，不通过父元素逐帧驱动后代样式。

`@starting-style`只提供首次入场的0位起点；基础规则始终是目标值，因此即使不支持该CSS特性也直接显示正确值，不加入兼容层、计时器或effect补动画。当前样例0的起点与终点同为0，不伪造额外滚动。组件没有useEffect/useState/rAF/setInterval、事件监听或需要清理的动画实例，没有React每帧渲染。

`style.css:890-895`在prefers-reduced-motion:reduce下对number-wheel禁用transition，直接显示最终位移；完整辅助数值仍保留。该数字变化是用户本轮明确要求，不推广到键盘焦点、按钮hover或高频公共操作。没有为数位添加hover动画或布局属性动画。
