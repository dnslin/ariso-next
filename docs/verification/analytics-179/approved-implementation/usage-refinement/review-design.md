## 整页、业务、控件对照

先检查整页及公共区域。四页保留桌面232px侧栏、访问统计当前项、品牌/账号区域、原正文起点和固定底栏；手机保留64px头部及16px正文内距。占用说明/返回统计沿原入口与48px底栏控件，不新增路径。产品继续组合OwnerShell，原型主题切换及“示例数据”工具栏没有进入产品。旧手机Figma公共Header仍是菜单文字示意，产品沿已有公共图标控件；本次未重设公共Header，不声称这处旧示意与实际页面逐像素相同。

再检查业务层级。泛描述、逐卡规则及页尾重复清理说明已从四页删除，保留标题、18px已登记总计、独立待核对状态和12px更新时间；手机待核对示例的时间自然另起一行。存储卡20px圆角、桌面24px/手机16px水平内距、20px纵向内距，名称与状态同排，字节合计随后呈现。四类对象继续52px数据行、标签左侧和数值右侧；最后确认时间独立保留。源码使用flex-wrap与原有卡片组合映射，不复制Figma绝对坐标。

最后检查控件及状态。源码实际采用HeroUI Chip soft/sm：success+Check表示启用，中性foreground 8%+Pause表示停用；warning+Clock3独立表示待核对。文字和图标保留，状态不只靠颜色，小标签不是按钮或大面积静态说明块。最终Figma PNG确为浅绿色、浅灰和浅橙，未把绑定代码中未展开的透明度误读成实心背景。

组成条仅由`confirmationStatus === 'confirmed' && knownBytes > 0`控制；enabled只决定启停标签。已停用完整卡仍保留非零组成，未知卡保留已登记字节而不画完整比例，零占用不造最小彩色段。各段消费四类真实字节，源码下方直接列数值。generatedAt映射摘要“更新于”，confirmedAt映射“最后确认”；null继续说明没有完整确认时间。这是代码与设计注记的核对，不是本轮真实API、零值或缺时间浏览器验证。
