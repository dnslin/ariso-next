# 版本分布与热门图片横排布局

用户在 2026-10-15 确认本地原型的“横排”方案，并要求其他地方先不动。批准来源为 `design-plans/analytics-brand-review-20261014/` 的方案 1，本次没有更新 Figma。

产品仅修改 `overview-panel.tsx` 和 `overview-content.tsx`：版本分布与热门图片分别占满一行；768px 起三种版本横向排列，手机保留三行标签、横条和数值。版本区增加原型中的颜色点、6px 横条与下分隔线。热门图片复用既有 HeroUI Button、缩略图、完整 Top 10 与详情入口。周期、查询、计数算法、趋势图、每日数值、公共外壳和侧栏均未调整。
