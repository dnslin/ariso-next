| 用户选择           | 实际呈现与源码佐证                                                                                                                      | 结论                                                                 |
| ------------------ | --------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| GitHub按钮补图标   | 两端按钮文字前已有16px正式GitHub标识，图文整体居中，浅色中识别清楚；源码使用 `@gravity-ui/icons/LogoGithub`，装饰性隐藏于读屏。         | 已表达。旧Figma纯文字由用户指令改写；深色图标与文字均保持清楚。      |

| 品牌设置紧凑重排   | 一个HeroUI面板内Logo/Favicon两行，预览与信息/状态形成左侧组，短选择按钮在右侧对齐，分隔线区分两资源；手机预览与信息并排，动作移至下行。 | 相比旧版全宽纵向卡，密度与操作归属更明确；没有为填空白新增展示功能。 |

卡片仍有合理呼吸空间。截图中面板右侧由对齐的选择操作承接，不再是整个宽表面只有左侧小块内容。手机格式在信息列自然换行，360px仍无横向裁切；按钮保留足够高度，没有用缩小字号或触达区换取紧凑。主操作明确，静态说明保持中性文字，没有大面积彩色说明块。手机深色下Logo/Favicon、Chip、分隔线和按钮仍可辨认。登录缺失素材以图标加“素材无法读取”文字呈现，保留站点名称；没有静默显示内置Logo或再次加入已删除的描述。
