## 待批准的局部方案

- 沿用 Figma 两素材卡片、独立选择/预览/更新/移除与固定操作栏；名称、描述仍在基本设置的站点信息组保存。
- 登录表单上方展示 Logo、站点名称、描述，复用公共背景、返回首页及已有认证字段。缺失 Logo 明确提示“素材无法读取”，仍允许输入登录信息，不冒充内置品牌。
- 选择文件进入预览；上传前标明待上传。已确认失败保留所选文件与预览，当前素材维持有效；响应丢失改为“结果待核对”，不宣称旧配置有效或新文件成功。
- 核对后展示服务器当前素材，允许采用服务器结果或保留所选文件继续上传；不自动重复请求。删除也区分提交中、失败、未知和读回结果。普通说明为简洁文字，明确成功使用中性 Toast，没有单独结果页。
- 删除确认及核对弹窗采用20px圆角、紧凑标题和操作区。这是本轮待批准的局部视觉方案，旧 `470:8953` 为12px圆角、24px标题及纵向操作，不能称逐像素沿用旧稿。
- 本轮只补品牌设置与登录缺口，不重排首页和分享。右上“原型演示”用于切换示例、主题和状态，不进入产品。
