上传 API 用法

用 Token 从脚本上传图片。


          

          

            在本机设置
            ARISO_UPLOAD_TOKEN，替换图片路径；完整示例还需替换存储和相册 ID。
          

          

            

              复制失败，请选中下方完整命令手动复制。
            

            
          

        

        

          
暂时无法读取站点地址和上传限制。请重试。

          
        

        

          当前站点单文件上限：50 MiB。规范默认值为 50
          MiB，站点可调整；接口每次只接收一个文件。
        

        查看 OpenAPI 3.0 规范 ↗
        

          请求参数
          

            

              
file

              
必需，一个图片文件，不能传 URL。

              
storageId

              
省略使用当前默认存储；空串不会使用默认。

              
albumId

              

                多个相册使用重复同名字段，ID 去重；不使用逗号串或 albumId[]。
              

              
tag

              
多个标签使用重复同名字段；逗号属于名称。

              
visibility

              
public / private；省略采用提交时默认可见性。

            

          

        

        

          结果与异常
          

            

              只有本次处理完成且图片 ready 才返回 201。私有图片链接需要所有者
              Cookie。
            

            

              400 输入 · 401 Token · 409 状态冲突 · 413 文件超限 · 415 格式 ·
              422 处理失败 · 502 存储依赖 · 504 等待超时 · 507 空间不足。
            

            
{ "imageId": "image-id", "status": "ready",
  "actualVersion": null,
  "defaultResolution": { "available": false, "code": "VERSION_UNAVAILABLE" } }

            

              仅为响应字段说明；完整规范列出真实保存版本、处理结果及
              requestId。未创建图片时 imageId 为 null、status 为
              not_created。处理失败保留真实 ID；status
              是当次结果，currentImageStatus 表示后续改变后的当前状态。
            

          

        

        

          超时或断线先到图库核对。等待超时不会取消处理；重复 POST
          可能产生新图片。此接口没有公开轮询或幂等键。
