## 状态和完成门槛

- **代表设计已补**：已有明确画板、状态或复用规则，允许对应实施任务引用；不代表任意组合或真实行为已验证。
- **实施时补齐并验收**：复用现有设计完成真实输入、数据组合与关联页面；若业务差异无法由既有规则表达，再补对应设计，不为全部排列预先复制画板。
- **已验收**：必须有该范围的真实检查结果。节点存在、连线有效、静态截图、用户认可和真实网页验收分别记录。

实施任务记录 PRD 条款、SPEC、UI 家族、两端状态节点、直接前置和验收证据。前置未交付的后置任务不能标完成。某个界面的缺口只阻塞该范围及完整验收，不阻塞无关底层任务；P2-* 准备任务不是全部功能实施清单。

## 真实验证清单

- 在对应前端检查 360/390/430、768 与桌面相关宽度；检查长内容、固定操作栏、安全区域、软键盘、表单错误、空态和浅深色。代表画板不等于所有宽度已通过。
- 实际操作输入、文件/目录/剪贴板、滚动、触控、焦点、Esc、键盘导航、缩放/平移/全屏能力降级、浏览器前进后退、主题与刷新保持。
- 通过实际请求验证已保存/未保存、失败保留输入、响应丢失先核对、请求竞态、部分失败和再次重试；固定成功跳转不作为证据。
- 上传/存储验证 S3 迟到写入最终收尾、AWS/R2/MinIO 单 PUT/Copy 共同容量、浏览器并发/预览释放和解析器；media/delivery 验证实际格式、SVG、资源故障、原子替换与内容权限。
- 认证、SMTP、Token、分享授权验证真实会话、OAuth、邮件、HTTP/缓存和持久化；统计验证计数批写、失败/退出恢复、时区/夏令时/365 天清理及对象责任去重。规模目标按 SPEC 执行，不能用原型合成数字替代。
