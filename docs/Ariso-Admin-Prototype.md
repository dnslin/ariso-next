## 统一布局

桌面画板 1440 × 1080，232px 侧栏，主区 32px 留白。页眉仅保留当前位置。侧栏底部统一为 D 字母头像、dnslin 和“站点所有者”，不再显示“演示数据”或旧页脚。

## 2026-09-14 布局与交互修订

### 对话框与操作栏

参考 [HeroUI Modal 官方组件](https://heroui.com/cn/docs/react/components/modal)及其官方样式源码，沿用 Ariso 配色。短对话框采用 480px 宽度、24px 内边距和圆角，分为标题、正文、底部操作三个区域。右上角关闭，次操作在左，主要操作在右。表单标签放在输入框外，输入框高 44px。

新建相册、标签、分享设置、修改密码和筛选等使用相同结构。图片详情保留大尺寸预览，关闭按钮移至右上角，复制和下载并排。标签编辑与删除提示对应当前标签名称，删除标签不会删除图片。本地存储已改为独立配置页。

设置页保留唯一主侧栏和顶部设置标签。页眉不再放用户信息。基本设置、图片处理、账号安全和邮件服务的操作栏统一位于右下方；长内容独立滚动。图片处理的预览和保存并排。

### 组件显示与配置页补全

- 用户反馈实际画布中部分按钮不显示文字。已将 142 个对话框按钮重建为独立文字层与自动布局，保留点击关系，避免继续依赖原先缩放后的按钮实例。危险操作使用浅色文字。
- 29 个原有下拉控件的值与箭头已拆为独立图层，箭头固定在右侧。邮件连接安全选择框也采用相同结构。参考 [HeroUI Select](https://heroui.com/cn/docs/react/components/select)。
- 压缩启用、最长边限制、分享启用、存储启用与 Path Style 等布尔项改用 Switch。开关组件提供开／关两种可切换状态；水印总开关连接对应的启用／关闭页面。参考 [HeroUI Switch 官方样式](https://raw.githubusercontent.com/heroui-inc/heroui/v3/packages/styles/components/switch.css)。
- 九宫格组件：74:935，包含左上、上中、右上、左中、居中、右中、左下、下中、右下九种状态。点选后改变高亮并显示当前位置。位置选择移至水印区靠前位置，首屏可见。关闭水印时显示禁用状态。对比预览仍是固定示例，不会随九宫格位置实时重新处理图片。
- 邮件服务：34:710。主机、端口、连接安全、SMTP 用户名、发件人名称、发件人邮箱和密码均使用外置标签。前六项按两列排列，密码单独一行。测试和保存仍位于右下方。
- 本地存储编辑：77:757；新建：77:924。包括名称、相对路径、实际目录提示、启用开关与默认存储开关。有图片引用时路径不可编辑。旧本地存储弹窗已移除。
- 添加存储页可在本地存储与 S3 之间切换；列表中的本地配置入口进入独立编辑页。

## 功能规则

- 相册不是文件夹，删除相册／标签不删除图片。
- 分享只展示公开图片，不改变图片可见性。
- 回收站不自动清理，仍占空间；永久删除与恢复明确区分。
- 图片选择只覆盖当前已加载范围。
- 压缩初始示例使用 WebP / 82；缩略图固定 WebP / 640px / 80；水印关闭。基本设置展示的是示例已配置站点，并非所有字段都代表初始化默认值。
- S3 连接测试包括写入、鉴权读取、匿名访问拒绝和删除。
- 页面不加入公开注册、文件夹体系或网页日志中心。
