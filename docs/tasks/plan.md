## 3. 后续维护

1. 按 [PRD](../product/Ariso-PRD-v1.1.md)和[业务规格](../product/CAPABILITY-MAP.md)确定范围，核对真实调用方与直接依赖。
2. 界面变更遵守[设计交付规范](../design/handoff.md)，复用已有组件与已批准交互。
3. 按[任务模板](./todo.md#实施任务模板)记录交付、适用检查与证据；检查规则统一见[执行约定](./execution.md)。
4. 发布、升级与恢复按[部署](../guides/deployment.md)和[升级指南](../guides/upgrading.md)执行。

已归集的常见问题和验证经验见[维护指南](../guides/maintenance.md)。历史任务图检查证明定义完整和依赖无环，不证明 GitHub 自动证据校验或合并拦截已经配置；此前的 P2-DEPENDENCIES 未实施记录保持不变。
