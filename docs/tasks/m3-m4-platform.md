- 真实验收：UP-07–13/23；使用 R2、SeaweedFS 当前矩阵（按[执行约定](./execution.md#对象存储验证目标调整)，旧“三服务”不恢复 AWS 门槛，也不把 AWS 记通过），覆盖真实直传/中转、总并发 3、源变化、200 内错误、Copy 响应丢失、取消/到期/旧签名重写、重启、跨盘与空间不足。断言终态不复活、引用/用量转移和已知 Key 清理；迟到对象不以一次 HEAD 404 宣称永久消失。
