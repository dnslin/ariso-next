## 逐项结论与差异归属

1. **整页及公共区域。** 先核对两端品牌、侧栏/顶部菜单、账号、当前项、正文起点和固定底部操作，再核对指标及业务内容。现有代表具有相同阅读层级：桌面四指标横排，手机2×2，后续图表与排行堆叠。旧图有“工作空间”面包屑；统计主节点该链接实际跳存储页 `30:1413` / `102:1231`。消费文档明确由现行 handoff 和共享 OwnerShell / AdminShell 覆盖这些历史差异，未把旧跳转或文字菜单当作必须复制的设计。常驻水绿静态说明与用户最新偏好有差异，文档将简洁说明及必要区域原型收口交#179，动态错误与旧值仍须可读；本DG未批准新方案。

2. **业务布局与读数。** 周期、固定指标、三版本、范围/时区、今日截至更新和每日文本值表达可复用。手机首屏的主统计及360主题截图只显示趋势卡顶部，后续图表、排行和版本数据由完整文字回读确认；待核对手机截图只见本地存储，S3语义来自节点文本。文档保留真实滚动、短视口、键盘/点击读数和底栏遮挡验收，未从首屏截图推导全内容通过。R6三个主题代表没有原型动作，不能替代业务流程。7天每日文本的七行合计2146与代表趋势一致，只能证明该组设计样例的表达，不能验收真实统计。

3. **排行和异常导航。** 两端历史排行中的正常/私有/停用行没有详情跳转；回收行只指向列表 `30:1037` / `102:852`，未定位具体记录。五项样例不足以证明完整十项、并列顺序和长名称。消费文档逐项要求按实际身份/管理目标接正常、私有、停用及回收记录，永久删除保留通用占位和数字且无内容入口；逐张异常定位另按现有模块能力收口。缺口明确归 T-ANA-05 / #179，没有新增未实现筛选参数或用固定行号导航。

4. **详情统计表达。** 两端详情节点完整文字和截图均没有单图统计区域。新增区域及加载/零值/统计独立读取失败/旧值/401/404等状态由#179先提供可查看原型并取得批准；统计内容按实际API字段，不增加单图逐日趋势或周期版本拆分。详情与统计在页面入口组合，不改变 library / analytics 模块职责。

5. **状态与真实验收。** 旧数据、读取失败、延迟/漏计、真实零值和空间未知分别交接；待核对保留登记值和未知数量，不绘完整比例，停用不清零。文本、reaction或静态截图未替代10秒刷新、隐藏暂停/恢复、迟到响应、URL days、注销缓存、真实定位和主题组合。桌面/手机、浅深/系统主题、360/390/430/768、短视口、44px适用点击目标、键盘焦点均交#179依执行约定取得真实证据；取消物理设备实测不记为通过。
