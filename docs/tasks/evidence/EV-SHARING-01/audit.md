## 发现与修复

1. **Required，已解决：** `/private` 原来只是所有者会话探针，不能证明真实私有内容权限。已删除该探针，新增生产图片与管理入口测试；17 项分享集成测试通过。
2. **Required，已解决：** 旧 refresh 尚未结束时立即隐藏、恢复，会被旧 pending 状态挡住。离线失败证据保留真实 Node 26 环境；修复后的 Node 24 回归、默认单元回归和真实隐藏恢复实验均通过。旧周期的 finally 不能清掉新周期。
3. 首次集成启动失败来自日志就绪早于 HTTP 可用。启动器现等待实际 `/control` 200，并保留期限、取消、服务日志和失败原因；受影响集成测试重跑通过。
4. 首次浏览器隐藏检查会因 Ego 的页面观察调用激活页面而改变被测状态。现使用不会激活页面的 `page.events()` 读取真实 Runtime binding 事件；隐藏等待期间不使用该页面的 evaluate/cdp/waitForFunction。
5. 成功后的观察器注册已按实际生命周期拆除。[CDP 官方协议](https://github.com/ChromeDevTools/devtools-protocol/blob/master/json/js_protocol.json)说明 `removeBinding` 取消事件订阅；本次不依赖它删除全局函数，也不为不存在的函数缺失风险追加检查。

原未使用的 member 控制现在由真实隐藏恢复场景消费，私有和回收两种变化均有断言，相关 Optional 已闭合。
