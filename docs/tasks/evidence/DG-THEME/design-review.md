错误文字阈值依据 [W3C SC 1.4.3](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)：普通文本至少 4.5:1，12px 错误文案不属于大字豁免。独立使用实时浮点 sRGB 值按相对亮度公式复算为 4.356:1。禁用控件本身属于该条款豁免，不能据此将必读错误、禁用原因或未禁用的正文也豁免。本次仅确认这个具体颜色组合的缺口，不据此宣称全站所有颜色均通过或均失败。

## 最终交接复核

已复核 [T-SITE-05 的 DG-THEME 正文](../../m3-m4-experience.md#dg-theme-对-t-site-05-的核对结论)、[统一证据](./README.md)、gates、设计目录与 acceptance 的本次差异。结论：文档设计适用核对通过；没有尚未交接的阻断性设计表达缺口。

最终正文正确区分主题基础接入和待实现选择器，保留唯一直接消费者、11 项语义映射、三偏好与解析颜色的区别、挂载前状态、真实验收入口及当前业务边界。浅色 12px 错误文字的具体对比不足、两项 CSS 漂移和旧 R6 被当前规则覆盖的范围已明确归属 T-SITE-05/#197；需要改变已确认视觉时仍先给局部原型取得批准，没有由 DG 擅自修改设计。

复核中另发现统一证据的 SPEC-site §6 片段漏写“素材”，已通知实施者修正到实际标题；此为文档定位修正，不影响上述设计适用结论。最终适用文档检查仍由实施者统一执行，评审不替代检查结果。
