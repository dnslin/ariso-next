## 具体差异与交接

Ariso的primary映射HeroUI accent，Ariso的accent映射边框，二者名称不能直接等同。完整映射与实施责任在消费任务维护。明确实现偏差为Light `--muted=#41445B` 对实时约#2D334A、`--focus=#287E79` 对实时#386176；其余部分HEX已与sRGB四舍五入一致，不笼统描述全套颜色错误。本DG不改产品颜色。

[contrast.json](./contrast.json)用实时变量的浮点sRGB计算相对亮度，再计算 `(L亮+0.05)/(L暗+0.05)`，只测不透明语义色对。深色正文/background为15.528、正文/surface为13.674、次要文字/surface为7.877、主按钮深字/品牌黄为10.710，不能据此宣称照片叠字或全部控件通过。

明确设计缺口为浅色规范 `266:1574/266:3471` 的12px错误文字：destructive/surface为4.355990547（报告显示4.356），低于[W3C普通文字4.5:1参照](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)。#197负责提出该错误文案局部可读性修正原型并取得批准，再实施/同步对应设计；本DG不指定新色值或重审整个产品配色。深色错误/surface为6.533，不扩大成所有主题错误。真正禁用控件有对比豁免，但仍可读的错误/禁用原因说明不是自动豁免；图表与必要控件按[非文字对比参照](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)和实际相邻背景分别核对。

另一明确状态缺口是挂载前尚不知道浏览器偏好；#197沿库标准挂载处理，不虚构服务器加载/保存/成功结果。主题无远端列表或空结果，不适用网络读错/保存中页面；业务数据的加载/空/错误/成功/禁用仍沿各模块容器。若新状态改变结构或视觉，消费任务先提供局部原型批准，不能用本DG记录当设计批准。
