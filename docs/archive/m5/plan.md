## 保留决策

- M3/M4 按交付能力分组，按实际提供方依赖逐步接通，避免整模块互相等待。模拟界面与真实集成交付分别验收。
- 单一任务只承担一个主要结果，桌面与手机属于同一功能范围；产品需求、已批准视觉和实际检查分别有来源。
- 任务定义与需求映射作为历史材料追溯；当时的本地无环检查不等于 GitHub 自动合并拦截已配置，旧检查器不再运行。
- 外部服务矩阵、设备实测及发布检查时机统一在[执行约定](https://github.com/dnslin/ariso-next/blob/d2e2267aca1f3551c41ce809a49bcc7b99016b66/docs/tasks/execution.md)维护，不从旧计划恢复已取消要求。
- 历史尚未发布、未验证和失败记录按当时状态解释。发布事实及用户手动验收确认各自保留，不互相冒充。
