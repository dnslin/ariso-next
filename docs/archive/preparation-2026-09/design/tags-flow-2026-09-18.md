## 本批交互与规则

- 创建填写摄影后，结果列表新增摄影并显示 0 张图片，计数从 9 到 10。空名称、51 字符超长、换行／控制字符及创建失败分别保留错误说明和修改入口；超长输入在框内省略，不撑开布局。
- 创建 go 命中已有 Go，保留已有显示形式和关系，不创建重复标签。仅修改 Go 的大小写也不更名。
- 旅行重命名远行后，列表和标签图片查询均显示远行，原 3 张图片关系保留。修改为另一个已存在的 GO 时明确冲突，不合并标签。
- 删除旅行后列表从 9 到 8；删除 Go 后列表也从 9 到 8。删除立即移除包括回收站在内的所有关系，不删除图片。同名重建不继承关系，恢复回收图片也不会补建已删标签。
- 已在上传中创建的空标签不会因上传取消或失败而消失，提供手动删除入口。0 张仅代表正常图库数量，不承诺回收站没有关系。
- 加载失败、保存失败、删除失败、对象已不存在与结果未知分开；结果未知先刷新核对，不自动重复提交。
- 正常图库数量包含私有、处理失败和存储停用成员。停用存储不阻止标签元数据管理；实现不得为此增加文件探测或读取。
- 主列表与结果列表复用同宽列，底部分页固定。手机正文独立滚动；四组阅读入口使用固定编号列和左对齐标题。

## 固定样例及尚未覆盖内容

这些画板用于查看设计状态，不会实际输入、搜索、保存或删除数据。名称搜索入口跳到固定 summer 无结果页；只展示默认 40 条、单页样例，20/80 与真实翻页仍需交互验证。规范化、Unicode 完整大小写折叠、并发唯一键与百分号／下划线的字面搜索规则继续以规格为准，不把静态校验画板当实现证据。

完整主线以旅行→远行、摄影创建和 Go 空标签为样例。其他既有标签弹窗保留原位，但未为每个名称补齐连续结果；结果列表再次编辑／删除不构成完整状态机。摄影和远行结果行的部分后续编辑／删除入口未连通，避免跳到另一标签弹窗。全局导航返回基准列表时数据也不会动态延续。

旅行与远行的图库筛选各展示 3 张有缩略图的图片；Go 和摄影各有空结果。[图库返回回归](./library-return-regression-2026-09-19.md)已连接旅行／远行各自的网格与瀑布流、第一张 forest-light 的四版本详情和大图返回，详情标签同步显示对应名称。其他卡片、查询输入、选择与批量关系仍未连通；真实标签 ID 查询、URL 历史、改名后查询保持和逐张图片操作归 LIBRARY 集成验收。

长名称画板以 51 个汉字展示上限反馈；换行示例用 ↵ 表示不可用字符。其他 Unicode 等价、空格规范化、组合字符和并发删除场景需在开发中验证。批量添加／移除标签、上传期间目标删除沿用 LIBRARY/UPLOAD 的专项范围，不在标签管理页增加重复入口。

DES-06-TAGS 保持待查看与交互验收。深色、更多尺寸、键盘和触摸未验证，尚未整体关闭设计任务。
