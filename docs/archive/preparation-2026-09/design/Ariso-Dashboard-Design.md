# Ariso Dashboard 设计

## 目标

在现有 Figma 文件内新增所有者工作台总览，使用 sidebar 布局。沿用 Ariso 品牌黄、水绿、暖白、深色文字、Caveat 标识与 Inter / Noto Sans SC 字体。参考 HeroUI Card、Table、Tabs 的层级、圆角、控件密度与状态，不声称使用官方 Figma 组件库。

## 信息架构

侧边栏分为：工作台；内容（上传图片、图库、相册、标签、分享管理、回收站）；管理（访问统计、存储管理、站点设置）。上传 API Token、账号、图片处理和 SMTP 等设置归入站点设置，不增加 PRD 明确排除的网页日志中心。

总览包含四项指标：图片数量、相册数量、今日访问、累计访问；访问趋势提供 7 / 30 / 90 天；存储卡展示 Ariso 文件实际占用及原图／派生／回收站分布。底部为热门图片排行与处理异常提示。

## 布局与视觉

桌面 1440 × 1080，侧边栏 232px，主区左右 32px 间距。侧边栏使用暖白底与水绿细边界，选中项为浅黄色胶囊。品牌字体缩小到 48px，不沿用首页超大字号。

主区使用圆角 20px 卡片与水绿浅边框。上传主按钮、选中周期与趋势线使用黄色。图表图区不铺点阵，避免妨碍读数。HeroUI 的组件结构用于设计映射，不复制默认蓝紫配色。

## 数据与语义

所有数字为演示数据。访问按 PRD 第 19 节定义：公开图片的有效访问；不包含缩略图、私有图片与所有者访问。S3 表示已签发有效访问地址，并不代表完整下载。每日数据按站点时区。无独立访客、地区、设备或来源站点指标。

演示基础用量：图片 1,284，相册 24，今日访问 326，累计访问 48,620。文件占用 8.6 GiB：原图 6.2、派生 2.1、回收站 0.3；本地 3.2、S3 5.4。空间条表示组成，不表示未定义的磁盘容量或套餐配额。

## 原型范围

交付总览及趋势切换状态，支持统计口径说明与处理异常详情。侧边栏覆盖功能入口的信息架构；后续已补齐后台页面，见 Ariso-Admin-Prototype.md。图表为静态演示，不连接真实数据。

上传按钮与侧栏上传入口打开上传弹窗，选择图片按钮展示原型边界说明，不读取本地文件。周期切换仅改变趋势图；热门图片维持明确标注的最近 7 天范围。
