## 回读范围与引用规则

2026-09-17 重新读取全部两个页面 `0:1`、`97:748` 的目录、节点文字、组件、变量和原型目标，并结合十份已确认 SPEC 复核。原始回读摘要及本轮新增画板校验见 [Figma 审计证据](./verification/figma-audit-2026-09-17.json)。

`UI-*` 是稳定的页面家族键，供规格、覆盖表和实施任务引用。它不等于路由，也不随 Figma 节点重建而改名。任务需同时引用家族键和本次实际使用的节点；具体路由在所属业务规格中确定，已由 PRD 指定的 `/setup` 保持不变。

每个家族的完成范围由“主页面 + 相关状态 + 缺口任务”共同确定。节点存在只代表已索引设计，不能将整个家族标为业务已完成。下表手机找回密码已实时核实为 `102:3100`。

当前回归与剩余责任统一见[全量原型回归](./prototype-regression-2026-09-19.md)。最近的业务设计补充见[六个子Agent并行补全目录](./parallel-design-completion-2026-09-19.md)，包括批量关系、禁用处理、特殊格式、连续设置、表单异常和主题屏宽。此前[图库／标签返回](./library-return-regression-2026-09-19.md)及[分享／地址](./context-address-regression-2026-09-19.md)仍有效。历史批次的“下一批”是当时进度，不代表当前仍缺少整组页面。

## 公共页面统一规范与本轮修正（2026-09-17）

用户指出非后台页面缺少明确的返回入口，且初始化／密码重置等新页面遗漏了首页的双柔光。本轮修正桌面、手机各 25 个完整公共画板，共 50 个；不包含后台上传页或独立浮层。新规范优先于早期页面截图与说明。

- **页面级返回**：除首页外，左上角统一放置明确的“← 返回首页”。共 48 个入口，44 个新增，4 个既有入口统一为 112×44px；目标是对应桌面／手机首页，不依赖浏览器历史，因此从邮件或外部地址直接进入也有出口。
- **流程内返回**：找回密码保留“返回登录”；重置页保留登录／重新申请入口；初始化保留“上一步”和返回设置。这些操作表达明确的目的地，不用一个含义不清的“返回”替代全部操作。时区选择的取消仍返回来源状态并保留原值。
- **双柔光**：所有非后台完整页面及其错误、处理中、成功状态共用右上淡黄、左下水绿。直接沿用首页的径向渐变、透明度和尺寸关系，放在内容底层。背景是装饰，前端不接收点击、不进入键盘焦点或辅助阅读；不能遮挡表单和按钮。浮层继承所在页面背景，不在每张浮层卡片内再画一组柔光。
- **手机布局**：顶部返回入口与品牌、正文分开留位；初始化和重置画板正文从 76px 后开始，保留纵向滚动能力。现有 390×844 画板正文未越出视口；更短屏幕及软键盘下继续滚动，不能固定高度裁掉操作。
- **实现与后续补图**：未来匿名分享等非后台页面也适用这套背景与明确出口要求。前端任务引用页面节点时，同时验收正常／异常状态的背景和返回路径。初始化返回首页不等于放弃或创建账号；提交中离开页面也不能显示“服务端操作已取消”。
