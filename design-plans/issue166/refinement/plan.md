# Issue #166 人工验收交互调整原型

2026-10-06。依据用户三张反馈截图，当前实现、设计交接与 Figma 的桌面/手机主节点 34:586 / 102:1837、创建 43:434 / 102:4345、完整值 249:1434 / 249:3557。本方案待用户批准，不改产品源码或覆盖获批画板。

- 信息图标放在“上传 Token”标题旁；悬停、键盘聚焦及点击展示站点时区和过期清理说明，保留完整含义。
- 用法图标在桌面标题操作区、创建按钮之前；手机移到能力说明右侧，避免压缩标题和主操作。当前点击显示尚未开放的简短说明。未来用法采用独立页面，便于长命令、参数、错误及返回管理页；原型工具栏提供未来布局预览，不把示意页当成当前能力。
- 创建标题保持稳定。HeroUI RadioGroup / Radio 用永不过期、指定时间直接表达互斥选择，选择指定时间展开既有 HeroUI DatePicker。移除取消和整宽期限切换按钮，创建以短48px按钮在右下收尾，右上关闭负责退出编辑。
- 完整值用 HeroUI 只读单行 Input 组合等宽字体与复制图标，横向滚动且可完整选择，避免换行及固定三行空白。当前 HeroUI 3.2.6 未导出 Code / Snippet；Token 没有代码语法，无需额外高亮依赖。复制图标44px点击区，成功中性反馈、保留弹窗和选择；拒绝显示手动复制说明。
- 移除我已保存关闭入口。关闭、Escape或点遮罩仍触发无法再次查看的确认，取消提醒回到同一完整值。不会因为点击复制而假定用户已经另行保存。

原型复用真实 AdminShell、SettingsHeading、SettingsCategories、TokenExpiryField 与现有 HeroUI/Lucide；所有记录和 Token 均为不可用示例，不请求真实业务接口，不修改人工验收数据。桌面/手机、浅深主题、短视口、tips、有效期、代码框、复制成功/拒绝和关闭提醒先行核对。批准后再实施产品、补行为测试并同步受影响 Figma 状态；现有未知结果核对和生命周期接口继续保留。
