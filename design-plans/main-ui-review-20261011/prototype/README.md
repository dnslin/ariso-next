## 数据边界

- 不请求真实业务接口。上传只读取选中文件的本地缩略图，后续结果为模拟。
- 设置、创建、恢复、删除、扫描与连接测试均为内存演示，不代表真实业务结果。刷新或切换数据状态会重置演示数据。
- 图片复用已有原型素材。壳层、主题和 HeroUI / Lucide 来自当前项目依赖。
- 错误、待核对、路径只读原因和必要确认仍直接显示。通用规则收进帮助入口。

## 运行

在项目根目录，使用 Node 24.18.1：

```sh
node design-plans/main-ui-review-20261011/prototype/build.mjs
node design-plans/main-ui-review-20261011/prototype/start.mjs
```

生成文件、服务日志和截图位于 `.data/main-ui-review-20261011/`。服务绑定 `127.0.0.1:61510`。启动前确认端口没有现有服务，避免重复启动。
