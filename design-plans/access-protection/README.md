# 访问防护交互原型

状态：用户已批准 Tips 精简版原型并授权正式开发。此目录仍是隔离原型，不连接真实服务；正式实施与验证见[实施记录](../../docs/verification/access-protection/README.md)。未修改生产配置或 Figma。

## 查看

- 访问防护：<http://127.0.0.1:3168/settings/general/access-protection>
- 入口位置：<http://127.0.0.1:3168/settings/general>
- 右上角“演示场景”可切换保存失败、结果未知、会话失效、IP 配置待核对、访客限频状态。
- 所有设置仅保存在当前原型的内存中；页面之间保留已保存值，刷新重置。不会调用正式 API。
- “基本设置”仅作为新入口的上下文，既有字段只读；其它后台页面不在本轮原型范围。

## 设计范围

入口采用“基本设置 → 关联设置 → 访问防护”，不增加侧栏一级入口或新的设置分类。子页沿用品牌设置的返回方式、最大 960px 内容宽度和固定底栏。

三个可编辑项：

| 配置         | 初始值      | 展示规则                             |
| ------------ | ----------- | ------------------------------------ |
| 防刷模式     | 仅观察      | 关闭、仅观察、启用拦截，使用互斥单选 |
| 持续请求频率 | 10 次/秒/IP | 正整数；字段中直接显示单位           |
| 突发请求额度 | 200 次/IP   | 正整数；说明用于容纳集中加载         |

所有者豁免是固定说明，不提供关闭豁免的设置。按本轮反馈，页面仅常驻短句“已登录所有者免于此限频”；S3 直连及签名复用边界放入标题旁“防护范围”Tips。

关闭模式保留已保存额度。仅观察记录潜在命中，不阻止访问。启用拦截之前需要确认真实 IP 配置；本原型通过演示面板模拟这一状态，并未进行真实检测。

## 交互

- 模式与数值编辑后，底栏提示未保存；点击保存展示 pending 和成功通知。
- 已知保存失败保留输入，允许手动再次保存。
- 保存结果未知时禁止重复提交，提供“核对已保存设置”。
- 会话失效保留输入，展示重新登录入口；原型仅模拟恢复会话。
- 返回按钮、侧栏站点设置与品牌入口在有未保存修改时提示确认。
- 真实 IP 尚未确认时禁止保存“启用拦截”，关闭和仅观察仍可操作。
- 访客状态沿现有黑色查看器和错误卡片展示；1 秒后允许手动重新加载，不自动重试。
- 演示工具位于产品画面之外，不进入正式 UI。

## 复用与差异

直接复用 `AdminShell`、`SettingsCategories`、`RelatedSetting`、`StorageTip`、`ThemeSelector` 和正式全局样式。表单使用 HeroUI RadioGroup、NumberField、Form、FieldError、Button、Card、Chip、Modal、Toast，图标来自现有 Lucide。

纯原型不使用会调用身份服务的 `OwnerShell`。导航结构仅为原型展示，未修改正式公共来源。原型账户和设置摘要均为示例。

视觉依据为当前产品组件及 `docs/design/handoff.md`。`evidence/reference-settings.png` 是 Figma UI-SITE 桌面 30:1601 的参考截图；该历史画板的部分导航、说明与标题已由交付规范中的后续批准条目替代。本轮已按用户批准的 Tips 精简版原型实施，Figma 尚未同步。

## 已运行检查

在 `prototype/` 内，使用 Node v24.18.1 和仓库已有依赖：

```sh
node ../../../node_modules/prettier/bin/prettier.cjs --check app
node ../../../node_modules/eslint/bin/eslint.js app --max-warnings=0
npm run typecheck
npm run build
npm run start
```

结果：格式、ESLint、类型与原型构建通过。预览监听 127.0.0.1:3168。

通过 `ego-browser nodejs` 运行真实浏览器检查：

- 保存、数字校验、建议值、关闭模式、已保存值跨页面保留。
- 页面返回与侧栏返回的未保存确认。
- 保存失败后重试、未知结果核对、会话失效恢复。
- IP 未确认时禁止启用拦截。
- 访客等待后手动重试、样例图片加载和 Escape 返回。
- 手机全屏菜单、主题切换、字段键盘遍历、帮助弹层 Escape 回焦。
- 1440×1080、390×844、360×640、768×1024 布局；深色桌面和手机；没有横向溢出，固定保存区保持在视口内。

本轮内置浏览器出现标签页失联，因此改用项目常用 Ego 浏览器完成检查。切换开发预览到构建预览时，浏览器曾记录旧 HMR 连接失败；保留在 `evidence/browser-checks.json`。新构建重新加载后的独立检查见 `evidence/browser-final.json`，没有捕获运行错误或警告。

## 未验证与下一步边界

- 模式行只保留名称和短标签；完整说明放入“防护模式”Tips。

用户已确认入口、页面布局、设置项和反馈方式。后续正式开发及正常浏览、外链嵌图、200 张 ZIP 验收在实施记录维护；原型中的模拟结果不作为正式验收证据。
