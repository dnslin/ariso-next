# 通知、回收站与搜索体验修订计划

本轮沿用现有 HeroUI、页面结构和 P2 原型。`/trash` 的空白背景来自确认态替换了整个列表，并非跳转到外部地址。相册和单图清理的成功对话框只承担告知结果；结果未知、失败、批量逐项状态仍需可持续查看。

1. **成功反馈**：相册编辑/删除及单图永久删除，在服务端结果已确认成功后关闭操作层，回到原页面并显示简短 Toast。保留必要后果文案、列表刷新与失败/未知核对入口。创建相册、封面预览、上传扫描、Token 展示等有后续操作的弹窗不改。
2. **回收站永久删除**：确认时保持原列表、当前页与选中项在遮罩后可见；对话框只显示选中数量、不可恢复后果，以及“取消 / 删除”。跨页选择用一句短文案说明其他页数量。取消后保留选择；提交后显示现有逐项结果、核对和重试能力。
3. **批量结果**：顶部返回按钮改为“返回”，删除底部重复按钮。成功行默认只展示结果；技术任务信息收进可展开详情。失败和未知行保留原因及操作。桌面表格、手机折叠行检查长名称和窄屏换行。
4. **搜索入口**：图库、回收站的放大镜提交按钮放入现有搜索框，维持 Enter/按钮提交和清除规则。分享、相册等原有即时搜索不改变查询时机。
5. **设计与验证**：更新本地可交互原型及现有 Figma 图库、回收站、相册相关桌面/手机状态。补充行为回归；运行格式、lint、类型、构建、相关浏览器流程，并在 360/390/430/桌面宽度核对布局与焦点。记录本轮证据，不改写旧 P2 验收记录。
6. **分享设置补充**：用户在实施中补充分享页截图。把“重新生成地址”的图标与标题垂直对齐；分享中、已过期、已停用沿用软色状态组件，使用不同的轻量颜色。桌面和手机检查状态区及操作行，不改分享行为。

边界：不改变清理 API、任务核对、恢复流程或产品定位；不批量替换所有对话框。提交、推送、合并、发布留待单独指示。
