## 交互

- 根据用户后续反馈，改为品牌、封面、标题和图片列表随整页一起滚动。隐藏页面滚动条，不建立独立图片滚动区；保留滚轮、触控板与键盘滚动。
- 保留现有四／三／两列断点与网格 4:3 裁切；瀑布流完整显示原比例。
- 点击图片直接打开覆盖整个视口的大图画布。按原比例完整显示，剩余空间使用近黑背景，不裁切、不拉伸。
- 正常大图只保留左右箭头与右上关闭图标。箭头透明，无实体底色／边框。首尾不循环，也不显示对应无效箭头。
- 方向键、左右滑动可切图；双击／双指缩放及拖动由现有查看器提供；Esc 或关闭图标返回原列表位置并归还入口焦点。
- 手机封面最多 160px，桌面最多 280px；短窗口收缩封面，给图片列表留出可用空间。

## 复用与边界

复用 HeroUI Button／Link、项目品牌组件、字体、公共背景与图库位置算法。图标使用已安装的 Lucide。大图复用现有 Yet Another React Lightbox 和 Zoom；HeroUI 通用控件不提供完整大图手势与原比例显示能力。按钮类型和查看器官方 API 已核对。

18 张照片是原型样本，使用本地保留的 Wallhaven 原始文件；来源在 `samples.json`。封面、名称、简介、数量不代表真实分享数据。未接入密码、分页、权限刷新及异常状态。这些生产能力在获批后的实施中保留现有契约。

此原型展示浅色列表及固定近黑图片画布。产品的深色主题、真实接口联验、Figma 对照和正式页面人工验收留待批准后实施。

## 运行

从仓库根目录，使用 Node 24.18.1、现有 pnpm 11.19.0 与已安装依赖：

```sh
node design-plans/share-viewer-review-20261014/prepare-assets.mjs
node design-plans/share-viewer-review-20261014/build.mjs
node design-plans/share-viewer-review-20261014/server.mjs
```

浏览器验证复用 Ego 任务空间 36：

```sh
ego-browser nodejs < design-plans/share-viewer-review-20261014/verify-browser.mjs
```

检查结果与截图保存到 `.data/share-viewer-prototype/evidence/`。原型构建、定向类型／静态／格式检查及浏览器交互检查只证明此独立原型，不代表产品构建、生产回归或人工批准。
